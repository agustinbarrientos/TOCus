# Shared theme

`@tocus/theme` owns brand assets, palettes, typography, and design tokens. `@tocus/ui` applies them to Mantine; application styles own layout and unique artwork.

## Icon assets and licenses

SVGs live in `assets/icons/`; the mascot is `assets/icon.svg`. Use the [shared UI](../ui/README.md) icon catalog.

The 15 replacement and control SVGs carry Font Awesome Pro v7.3.1 commercial-license notices and Fonticons, Inc. copyright notices. `circle-check.svg` retains its Font Awesome Free notice. Preserve these notices when editing or distributing the SVGs. Their licenses are separate from the project's MIT license. This repository does not include the Font Awesome Pro license agreement or document permission to redistribute the raw assets.
